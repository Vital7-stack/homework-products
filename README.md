## Функционал

Проект реализует работу с сущностями «Товар» и «Категория» с поддержкой наследования и валидации типов.

### Базовые сущности

- **Класс `Product`** — базовый товар с полями: название, описание, цена, количество в наличии.
- **Класс `Category`** — категория товаров с полями: название, описание, список товаров.
- **Автоматические счётчики**:
  - `Category.category_count` — количество созданных категорий.
  - `Category.product_count` — суммарное количество товаров во всех категориях.

### Наследование и специализированные товары

Реализованы классы-наследники от `Product`:

- **`Smartphone`** — смартфон с дополнительными атрибутами: `efficiency`, `model`, `memory`, `color`.
- **`LawnGrass`** — газонная трава с атрибутами: `country`, `germination_period`, `color`.

### Контроль операций и валидация

- **Сложение объектов (`__add__`)**: разрешено только для экземпляров одного класса. При попытке сложить объекты разных классов выбрасывается `TypeError` (проверка через `type()`).
- **Добавление в категорию**: в `Category` можно добавлять только объекты `Product` и его наследников (валидация через `isinstance()`).
