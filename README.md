# homework-products

Проект реализует работу с сущностями «Товар» и «Категория» с поддержкой наследования, валидации и автоматического контроля качества кода.

## Функционал

### Базовые сущности

- **Класс `Product`** — базовый товар с полями: название, описание, цена, количество в наличии.
- **Класс `Category`** — категория товаров с полями: название, описание, список товаров.
- **Автоматические счётчики**:
  - `Category.category_count` — количество созданных категорий.
  - `Category.product_count` — суммарное количество товаров во всех категориях.

### Наследование и специализированные товары

Реализованы классы‑наследники от `Product`:

- **`Smartphone`** — смартфон с дополнительными атрибутами: `efficiency`, `model`, `memory`, `color`.
- **`LawnGrass`** — газонная трава с атрибутами: `country`, `germination_period`, `color`.

### Контроль операций и валидация

- **Сложение объектов (`__add__`)**: разрешено только для экземпляров одного класса. При попытке сложить объекты разных классов выбрасывается `TypeError` (проверка через `type()`).
- **Добавление в категорию**: в `Category` можно добавлять только объекты `Product` и его наследников (валидация через `isinstance()`).

## Реализованная функциональность (в рамках задания)

В рамках текущего задания реализованы следующие компоненты:

- **Абстрактная модель продукта**: создан базовый класс `BaseProduct` с абстрактными методами, определяющими контракт для всех продуктов.
- **Иерархия наследования**: классы `Smartphone` (смартфон) и `LawnGrass` (газонная трава) наследуются от общего класса `Product`, который реализует базовую логику.
- **Миксин логирования**: реализован `LoggingMixin`, который автоматически выводит в консоль информацию о создании объекта (имя класса и переданные параметры) при инициализации.
- **Тестирование**: написан набор тестов (`tests/test_products.py`), покрывающий базовую функциональность, наследование и работу миксина.
- **Контроль качества**: обеспечено покрытие кода тестами более 75 %, отчёт генерируется автоматически.
