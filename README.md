Домашнее задание: работа с сущностями «Товар» и «Категория».

## Реализованный функционал

- Класс `Product`: название, описание, цена, количество в наличии.
- Класс `Category`: название, описание, список товаров (объектов `Product`).
- Автоматические счётчики:
  - `Category.category_count` — количество созданных категорий.
  - `Category.product_count` — суммарное количество товаров во всех категориях.
- Покрытие тестами > 75%.
- Проверка кода линтером (flake8) в соответствии с PEP 8.


- **Наследование и новые классы**: реализованы классы-наследники `Smartphone` и `LawnGrass` от базового класса `Product`.

  - `LawnGrass`: добавлены атрибуты `country`, `germination_period`, `color`.
- **Контроль операций**:
  - Сложение объектов (`__add__`) разрешено только для экземпляров одного класса. При попытке сложить объекты разных классов выбрасывается `TypeError` (проверка через `type()`).
